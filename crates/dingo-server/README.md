# dingo-server

**AGPL-3.0-or-later** networked serve path for DingoDB: bounded accept loop,
authorization, protocol admission, TLS bind policy, and network Raft control /
data-plane glue.

Depends on `dingo-sdk` (collection + remote client types) and `dingo-cluster`.
The thin wire protocol lives in MIT `dingo-client`.

See `doc/LICENSING.md` for the multi-tier license map.
